Política de Privacidade do ClipCity

Última atualização: 24 de novembro de 2026

1. O que é o ClipCity

ClipCity é uma ferramenta pessoal, usada apenas pelo dono do canal ClipCity no YouTube, para enviar e agendar os próprios vídeos curtos (Shorts) nesse mesmo canal. Ela não é oferecida ao público e não tem outros usuários.

2. Dados do Google que o app acessa

Com a autorização do dono do canal, o ClipCity usa a YouTube Data API v3 com estas permissões:

  • youtube.upload: enviar vídeos ao canal do próprio usuário e definir título, descrição, tags e horário de publicação.
  • youtube.readonly: ler o nome do canal autorizado, para confirmar que o envio vai para o canal certo.

O app não lê e-mails, contatos, inscritos, comentários, histórico ou qualquer outro dado da conta.

3. Como os dados são usados e guardados

  • O token de acesso do Google fica guardado só no computador do dono do canal, e é usado apenas para enviar os vídeos dele.
  • Nenhum dado é enviado a servidores do ClipCity (não existem) nem a terceiros, e nenhum dado é vendido, compartilhado ou usado para publicidade.
  • O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

4. YouTube e Google

O ClipCity usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. Veja também a Política de Privacidade do Google.

5. Como revogar o acesso

O acesso pode ser removido a qualquer momento em myaccount.google.com/permissions. Depois disso o ClipCity não consegue mais enviar vídeos, e o token guardado no computador deixa de funcionar e pode ser apagado.

6. Contato

Dúvidas sobre esta política podem ser enviadas pelo canal ClipCity no YouTube.

Privacy Policy (English)

ClipCity is a personal tool used only by the owner of the ClipCity YouTube channel to upload and schedule their own Shorts to that same channel. It is not offered to the public and has no other users.

With the owner's consent it uses the YouTube Data API v3 scopes youtube.upload (upload videos and set title, description, tags and publish time) and youtube.readonly (read the authorized channel's name). No other account data is accessed.

The Google access token is stored only on the channel owner's own computer and used only to upload their videos. No data is sent to any ClipCity server (there is none) or to third parties, and no data is sold, shared or used for advertising. ClipCity's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

ClipCity uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions. Questions can be sent through the ClipCity YouTube channel.
